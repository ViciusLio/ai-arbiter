# Synthetic sentences to measure the detection of personal data, in English.
#
# Each line is one text. What should be found is written as [text](category). Lines
# with no label are there to count false positives. People, addresses and numbers are
# invented; IBANs, tax codes and cards are examples with a valid format.
#
# The set is small and was written by the author of the detectors: it gives an
# indication, not a guarantee. See docs/pii-evaluation.md.
